# 風の告非室

「風の告非室」網站正式上傳版本。

## 網站內容

- `index.html`：網站首頁與互動程式
- `assets/`：網站實際使用的圖片素材

## Vercel 部署

1. 將本資料夾內容上傳到 GitHub 儲存庫。
2. 在 Vercel 選擇 **Add New → Project**。
3. 匯入這個 GitHub 儲存庫。
4. Framework Preset 選擇 **Other**（若 Vercel 已自動判斷，可沿用預設值）。
5. Root Directory 保持儲存庫根目錄，Build Command 與 Output Directory 不需填寫。
6. 按下 Deploy，先確認 Vercel 產生的預覽網址。

## 更新方式

日後修改網站後，重新提交並推送到 GitHub；Vercel 會依連接的分支自動建立新部署。
